# AI-TicketX

AI Customer Support Ticket Triage System.

## Features

- Customer support ticket classification
- Category prediction
- Urgency prediction
- TF-IDF text representation
- Logistic Regression classification
- Confidence scoring
- Human review for low-confidence predictions
- Streamlit dashboard
- Historical ticket analytics

## Categories

- Billing
- Technical
- Account
- Product

## Urgency Levels

- Low
- Medium
- High

## Technologies

Python
Pandas
NumPy
Scikit-learn
TF-IDF
Logistic Regression
Streamlit
Plotly

## Workflow

Customer Ticket
→ Text Cleaning
→ TF-IDF
→ Category Classification
→ Urgency Classification
→ Confidence Check
→ Automatic Routing / Human Review
